# AI Workshop - OpenEdge ABL Project

Workshop project demonstrating OpenEdge ABL development, including a Business Entity architecture pattern (CustomerEntity, EntityFactory) contrasted with legacy fat-client code (ItemWin.w), and documentation for refactoring legacy code to the modern pattern.

## Contents

- `src/business/` - Business Entity classes and dataset definitions
- `src/` - GUI window procedures (CustomerWin.w, ItemWin.w)
- `doc/business-entity-pattern.md` - Business Entity pattern documentation and refactoring checklist
- `dump/` - Sports2000 database schema summary
- `.windsurf/` - AI assistant rules and workflows
